Added support for Cloud Flight S, Cloud Flight Wireless, Cloud Stinger Core Wireless + 7.1, Cloud Flight 2 (Dedicated Dongle), and Cloud Mix 2. New automatic headset detection and an updated Device page show supported features and connection details. Improved adaptive battery-time estimates and English, Portuguese (Brazil), and Spanish interface text. Cloud III S and Cloud Flight 2 require a Dedicated Dongle; Three-In-One monitoring is not supported.
